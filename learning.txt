COMMANDS-
ffmpeg \
-f pulse \
-i default \
-ac 1 \
-ar 16000 \
-f f32le \
pipe:1

Command Meaning:-
-f pulse → PulseAudio input
-i default → RDPSource
-ac 1 → mono
-ar 16000 → 16 kHz
-f f32le → 32-bit floating-point PCM
pipe:1 → audio file me nahi, stdout me bhejo
